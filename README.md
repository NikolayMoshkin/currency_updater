Демон, который раз в минуту должен:
- оправшивать несколько источников по http о текущем курсе доллара
- сохранять данные в базу: источник, дата и время, курс
- при запуске сервиса через cli с аргументом `help` должна выводиться информация о сервисе

Должен быть реализован graceful shutdown
Должен быть реализован working pool для опроса источников
Должна быть продумана возможность для авторизации для каждого источника отдельно
